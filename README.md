# Автосалон Subaru

Учебная модель двух автосалонов на Python с оконным интерфейсом Tkinter.

## Запуск

Нужен Python 3.10 или новее с Tkinter. Дополнительные библиотеки для программы не нужны.

```powershell
python main.py
```

В Windows можно открыть `Запустить.bat`. В PyCharm запустите `main.py`.

## Что умеет программа

- Случайный поток от 1 до 10 посетителей в день в каждом салоне.
- Продажи, резервирование, обмен машинами и закупки из Москвы и Ханко.
- Пополнение склада, сбор партий для автовоза и железной дороги.
- Расчёт выручки, хранения, прибыли, просрочек и потребности в деньгах.
- Изменение параметров, графики, таблица заказов и сравнение вариантов.
- Сохранение настроек в JSON, результатов в CSV и отчёта в HTML.

По умолчанию автомобиль стоит 2 500 000 ₽. Примерные цены за полный рейс: Москва — салон 90 000 ₽, Ханко — Москва 150 000 ₽, железная дорога 180 000 ₽. Склад: по 8 машин, порог заказа 7, пополнение из Ханко. Параметры можно изменить слева и применить кнопкой «Применить и сбросить».

Время дальних перевозок не задано и по умолчанию исключено. Зарплаты, налоги и проценты по кредиту не учитываются. Расчёт выполнен для одной условной модели автомобиля; ассортимент можно расширить в настройках. Подробные правила доступны во вкладке «О модели».

## Проверка и эксперименты

```powershell
python -m unittest -v
python student_experiments.py
```

Второй файл выполняет 8 отдельных годовых запусков, использованных в отчёте. Результаты сохраняются в `output/student_report/results.json`. Папка `output` не попадает в Git.

## Файлы

- `main.py` — интерфейс и управление запуском.
- `simulator.py` — модель и расчёты.
- `ui_components.py` — визуальные компоненты.
- `report.py` — экспорт HTML-отчёта из приложения.
- `test_simulator.py` — проверки модели.
- `student_experiments.py` — восемь примеров запуска.

Виртуальное окружение, настройки IDE, кэш и сгенерированные результаты исключены через `.gitignore`.
